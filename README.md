# 匿名交流掲示板（完全静的版）

Node.jsサーバーを使わず、**HTML・CSS・JavaScriptのみ**で動く掲示板です。
データの保存やログインなどのバックエンド機能はすべて [Supabase](https://supabase.com/)（無料で使える外部サービス）にまかせています。

これにより：
- サーバーを自分で立てて動かし続ける必要がありません
- GitHub Pagesのような「静的ファイルを置くだけの無料ホスティング」でそのまま公開できます

---

## 1. 最初に1回だけやること（Supabaseの設定）

### 1-1. Supabaseプロジェクトを用意する

以前Node.js版のために作ったSupabaseプロジェクトがあれば、それをそのまま使えます。
まだなければ [supabase.com](https://supabase.com/) で無料アカウントを作り、新しいプロジェクトを作成してください。

### 1-2. テーブルと関数を作成する

1. Supabaseのダッシュボードを開き、左メニューの **SQL Editor** を開く
2. `db/schema.sql` の中身を全部コピーして貼り付け、**Run**（実行）する
3. 「Success」と出れば完了です（この作業は最初の1回だけでOKです）

### 1-3. 管理者アカウントを1人だけ作る

このサイトには「新規登録フォーム」はありません。管理者になれるのは、Supabase側で直接作った1人だけです。

1. ダッシュボードの左メニューから **Authentication → Users** を開く
2. **Add user** をクリック
3. メールアドレスとパスワードを決めて入力し、作成する（メールアドレスは実在しなくてもSupabase内で使うだけなので、覚えやすいものでOKです）
4. これで決めたメールアドレス・パスワードが、あなた（Yuさん）の管理者ログイン情報になります

### 1-4. 接続情報をサイトに設定する

1. ダッシュボードの **Project Settings → API** を開く
2. **Project URL** と **anon public key**（公開用のキー）をコピーする
   （「service_role key」は絶対に使わないでください。これは秘密の鍵で、静的サイトに書くと誰でも見えてしまいます）
3. `public/supabase-config.js` を開いて、以下のように書き換える：

```js
window.SUPABASE_URL = 'コピーしたProject URL';
window.SUPABASE_ANON_KEY = 'コピーしたanon public key';
```

### 1-5. 管理者への自動ログインを設定する（任意・リスクあり）

`gate.html` で「108100308」を入力すると、**Supabaseの管理者ログインを自動で行ったうえで**管理者ページを開くようにしてあります。そのために、1-3で作った管理者アカウントのメールアドレス・パスワードを `gate.html` に直接書き込む必要があります。

`gate.html` を開き、以下の部分を書き換えてください：

```js
const ADMIN_AUTO_LOGIN_EMAIL = 'ここに管理者アカウントのメールアドレスを入力';
const ADMIN_AUTO_LOGIN_PASSWORD = 'ここに管理者アカウントのパスワードを入力';
```

**この設定には重大なリスクがあります。** 詳しくは次の「2. パスワード」を必ずお読みください。

---

## 2. パスワード（入場・管理者ページへの入口）

サイトを開くと、まずパスワード入力画面が出ます。

- **108801** → 通常のサイト（掲示板本体）に入れます
- **108100308** → 管理者アカウントへの自動ログインを行ったうえで、管理者ページ（admin.html）に移動します（削除・BANがそのまま使える状態で開きます）

**⚠️ 重大な注意（必ずお読みください）**：このサイトはNode.jsサーバーを使わない静的サイトのため、`gate.html` に書き込んだ管理者のメールアドレス・パスワードは、**サイトを見た人が「ページのソースを表示」するだけで誰でも読める状態**になっています。つまり：

- 108100308というパスワード自体だけでなく、**あなたの管理者アカウントの本物のメールアドレス・パスワードも公開されている**のと同じ状態です
- その情報を見た人は、108100308を知らなくても、Supabaseに直接ログインしてあなたと全く同じ権限（全スレッド・全レス削除、全ユーザーBAN）を、いつでもどこからでも行使できてしまいます
- GitHubのリポジトリを公開（Public）にしている場合は、リポジトリを見ただけでも同じ情報が手に入ります

このリスクを理解した上で、あえて利便性を優先する設定になっています。もし途中でやはり不安に感じた場合は、`gate.html` の `ADMIN_AUTO_LOGIN_EMAIL` / `ADMIN_AUTO_LOGIN_PASSWORD` を適当なダミーの文字列に戻せば自動ログインは失敗するようになり（108100308は管理者ページへの入口を開くだけになります）、admin.html側では通常通りメールアドレス・パスワードを入力してログインする形に戻せます。加えて、Supabaseの管理者アカウントのパスワードを変更すれば、それより前に漏れていた情報は無効になります。

パスワード入力状態は `sessionStorage` に保存されるため、**ブラウザ（タブ）を完全に閉じると自動的にリセット**され、次回開いたときは再度パスワード入力が必要になります（管理者としてのログイン状態はSupabase側の仕組みで保持されるため、108100308を毎回入力すればそのつど自動的にログインし直されます）。

## 3. 手元での動作確認

このサイトはただのHTML・CSS・JSなので、VS Codeの**Live Server**拡張機能で問題なく動きます（Node.js版と違い、サーバーの起動待ちなどは不要です）。

1. VS Codeで `public` フォルダ（または公開用フォルダ）を開く
2. `index.html` を右クリック → **Open with Live Server**
3. ブラウザが開いたらパスワード（108801）を入力して動作確認

## 4. インターネット上に公開する（GitHub Pages）

このフォルダ（`掲示板`）に、このサイトのファイル一式（`index.html`・`app.js`・`admin.html`・`admin.js`・`style.css`・`gate.html`・`gateCheck.js`・`identity.js`・`supabaseClient.js`・`supabase-config.js`、および `db/schema.sql`）をそのまま入れてあります。フォルダの中にサブフォルダを作らず、このフォルダ自体をGitHubのリポジトリにするのがおすすめです。

### 4-1. GitHub Desktopでリポジトリを作る

1. GitHub Desktopを開く
2. 左上の **File → Add local repository**（または最初の画面の「Add」）を選ぶ
3. このフォルダ（`掲示板`）を選択する
4. 「This directory does not appear to be a Git repository. Would you like to create one?」と出たら **create a repository** をクリック
5. リポジトリ名（例：`board`）などを確認して作成する

### 4-2. GitHub Desktopで公開（プッシュ）する

1. 変更されたファイルが左側に一覧表示されているのを確認する
2. 左下の「Summary」欄に一言（例：「静的サイトを追加」）入力し、**Commit to main** をクリック
3. 画面上部の **Publish repository**（2回目以降は **Push origin**）をクリックしてGitHubに送信する

### 4-3. GitHub Pagesを有効にする

1. GitHub Desktop右上の **View on GitHub**（または「Repository」メニュー内）からブラウザでリポジトリのページを開く
2. **Settings** タブ → 左メニューの **Pages** を開く
3. 「Build and deployment」の **Source** を `Deploy from a branch` にする
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
5. 数分待つと、ページ上部に公開URL（`https://ユーザー名.github.io/リポジトリ名/` の形）が表示されます

このURLを他の人に共有すれば、みんなで同じ掲示板を使えます。

## 5. 静的サイトゆえの制限（あらかじめご了承ください）

- **BANはブラウザ単位**です。同じ人が別のブラウザ・別の端末を使うと、BANされていない別人として扱われます（IPアドレスでのBANはサーバーが無いため実装できません）。
- **連続投稿の防止**は、ブラウザ側での簡易的な間隔チェックのみです（本格的なアクセス制限はサーバーが無いと実装できません）。
- 入場パスワード（108801 / 108100308）は上記の通り「見た目だけの関門」です。実際にデータを守っているのは、Supabaseのデータベース側のルール（RLS）と、管理者ログインです。

---

## 6. 主な機能（おさらい）

- 登録不要で閲覧可能、書き込むと自動で匿名ID付与（同じブラウザなら永続的に同じID）
- レスへの♡いいねとその数の表示
- お気に入りスレッドのブックマーク（ブラウザに保存）
- カテゴリ分けなし、最新レスのスレッドが一覧の一番上
- 1000レス到達で自動的に「過去スレ」へ移動し、書き込み不可に
- 管理者（Yuさん）は全スレッド・全レスの削除、ユーザーのBANが可能
- 一般ユーザーは自分が立てたスレッドのみ削除可能
- 通報ボタンで運営へ通報でき、管理者ページで確認・対応可能
